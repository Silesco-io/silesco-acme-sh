# Подключение PHP-библиотеки ACME

Версия 0.1.0-alpha.1; PHP 8.3+, без Yii, PostgreSQL, Vault и сетевых зависимостей.
Код публичного SDK — Apache-2.0. Библиотека формирует типизированные запросы и читает
результат через Executor; ACME и DNS API выполняет готовый acme.sh.

В Silesco запрос принимает существующий root bootstrap-путь. PHP не получает sudo,
Docker socket и возможность выполнять произвольные команды. Для стороннего проекта
нужно реализовать Executor вокруг собственного доверенного исполнителя. Готового
локального запуска процессов в первой версии нет. Каталог и модели переиспользуемы
без Silesco, но самостоятельно сертификаты не выпускают.

Каталог перечисляет все 191 DNS-драйвер acme.sh 3.1.4. Форма проверена только для
REG.RU, остальные честно отмечены как непроверенные и не могут получить выдуманные
поля. Реальные учётные записи провайдеров здесь не испытывались.

REG.RU: укажите логин и альтернативный пароль API. В настройках
https://www.reg.ru/user/account/#/settings/api/ разрешите публичный исходящий адрес
сервера, где выполняется acme.sh. В задания попадает только ссылка на credentials,
не их значения. Не сохраняйте форму в логах. acme.sh самостоятельно создаёт и
удаляет TXT; его account.conf и ответы API требуют защиты на стороне исполнителя.

Повтор неизменного задания должен вернуть ту же операцию; изменённое задание с тем
же idempotency key отклоняется. Опрос состояния не запускает выдачу повторно.
`issued` не означает активацию Nginx, доверие браузера или готовность PWA — это
доказывается отдельно владельцем конфигурации. Ошибки возвращаются кодами, без
сырых ответов провайдера. Недоступный провайдер не заменяется другим автоматически.

Установка: Composer path repository либо `node scripts/export.mjs ПУСТОЙ_КАТАЛОГ`.
Пакет можно включить в image без сети. Точный API и команды проверок находятся в
[руководстве разработчика](../integration.md) и [генерируемом справочнике](../reference/api.md).
Тесты библиотеки не заменяют настоящую выдачу LE staging в установленной системе.
